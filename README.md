# fiberflow-project

Starlink-inspired React + Tailwind template.

## Quick start

1. Install dependencies:
   ```
   npm install
   ```

2. Start dev server:
   ```
   npm run dev
   ```

Note: If you haven't initialized Tailwind in your environment, run (after npm install):
```
npx tailwindcss init -p
```

This project already includes `tailwind.config.cjs` and `postcss.config.cjs`.
